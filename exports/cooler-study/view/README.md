# Shared 3D viewer assets

These meshes and [view.json](view.json) are generated by `cadagent.view.export_view` from the study's individual STEP files. They use the common cad-agent viewer, including its part visibility, section and explode controls.

Run `cad-agent site --serve --port 8766`, then open the **Cooler study → Interactive 3D** panel on the local site. The PCB, module and magenta module-axis references start hidden; enable them in the parts list.

The meshes are for visual review, not printing. See the [fit study](../../../docs/cooler-fit-review.md) for dimensional sources and unresolved mounting details. Rebuild from the [study tool](../../../tools/cooler_fit_review.py).
