# Cooler 3D viewer assets

These meshes and [view.json](view.json) are generated by `cadagent.view.export_view` from the cooler's component STEP files. They use the common cad-agent viewer, with part visibility, section and explode controls.

Run `cad-agent site --serve`, then open **Cooler 3D** in the top bar. The PCB, module and magenta module-axis references start hidden; turn them on in the parts list.

The meshes are for visual review, not printing. See the [fit review](../../../docs/cooler-fit-review.md) for sources and open details. Rebuilt by [tools/cooler_fit_review.py](../../../tools/cooler_fit_review.py).
