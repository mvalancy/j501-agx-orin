# Project lessons

Keep useful findings beside their evidence and related changes. Search existing design notes before recording a new incident; preserve other worktrees and running jobs. Local notes alone are not a published project handoff.

| Symptom | Canonical lesson |
|---|---|
| Lid ribs or intake ring hit a replacement cooler | [Keep cooler variants and seating datums separate](inbox/2026-10-27-cooler-datum-and-variant.md) |
| Ribs or bosses fill a screw hole or counterbore | [Cut every hole last; check every hole](inbox/2026-10-29-holes-cut-last.md) |
| Every rebuild changes every STEP file | [Make exports byte-reproducible](inbox/2026-10-30-reproducible-step.md) |
| Render antenna appears buried in a nut or its total height disagrees with a housing datum | [Separate antenna seating and generated bounds](inbox/2026-11-12-antenna-seating-and-envelope.md) |

See the [inbox](inbox/README.md) for dated findings and the [cooler fit review](../docs/cooler-fit-review.md) for current design evidence.
